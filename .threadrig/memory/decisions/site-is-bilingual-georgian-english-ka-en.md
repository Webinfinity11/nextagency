## გადაწყვეტილება
Site ships in Georgian and English with locale-prefixed routes (/ka default, /en). All copy lives in content files per locale; admin entities (blog posts, projects) will store both language versions. Georgian fonts must be supported.

## რატომ
User chose Georgian + English over single-language.

## უარყოფილი ალტერნატივები
